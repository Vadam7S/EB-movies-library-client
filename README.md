# EB Movies Library

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.29.

## Description
Web application for discovering and searching movies
using The Movie Database (TMDB) API.

Developed with Angular and TypeScript as part of
a technical assessment.

## Technologies
- Angular 21 LTS
- TypeScript
- RxJS
- CSS
- TMDB API

## Features
- Popular movies listing
- Movie search
- Movie details
- Responsive design

## Requirements
- Node.js 22.22.3
- npm

## Installation
Clone the repository:
  - git clone <repository-url>

Navigate to the project:
  - cd EB-movies-library-client

Install dependencies:
  - npm install

Instructions for configuring TMDB credentials.

## Development server
